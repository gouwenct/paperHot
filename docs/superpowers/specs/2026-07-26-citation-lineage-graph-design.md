# 引文谱系图设计（2026-07-26）

## 目标

在论文详情页下方新增"引文谱系"板块：以点线图展示当前论文的前置论文（它引用的关键文献）和后续论文（引用它的文献），节点可点击进入对应论文详情页并继续递归追溯，帮助用户追踪一个研究系列的思想来源与发展脉络。

## 已确认的关键决策

1. **后续论文筛选**：本地论文库优先 + 高被引补充。本地库中引用了当前论文的条目全部保留，再从外部信源按被引次数补充到约 6 篇。
2. **外部论文点击行为**：临时详情页 + 可选加入库。不在本地库的节点点击后实时拉取详情展示，提供"加入论文库"按钮；不点击则不写入任何本地数据。
3. **图的形态**：局部图 + 追溯路径高亮。每个详情页显示以当前论文为中心的一张图（上方前置、下方后续），用户一路追溯经过的论文保留在图中并高亮，可点击回退。
4. **多信源并行**：OpenAlex 与 Semantic Scholar 并行拉取，速度优先；合并时字段互补，更完整的字段补充进来。

## 数据层（后端）

### 接口

- `GET /api/lineage?doi=...`：返回当前论文的谱系数据 `{ center, predecessors: [], successors: [], sources: [], fetchedAt }`。
- `GET /api/lineage/paper?id=...`：为外部论文（不在本地库）提供临时详情页数据，支持 OpenAlex Work ID 或 DOI。

### 信源与并行策略

- **OpenAlex**（已接入）：前置来自 `referenced_works` 批量查询；后续来自 `filter=cites:` 查询，按 `cited_by_count` 排序。
- **Semantic Scholar**（已接入）：references / citations 接口，独有 `isInfluential` 高影响力引用标记与 citation intent。
- 两个信源**并行请求**，任一失败不阻塞另一方；全部失败时返回空谱系并注明来源不可用，不伪造数据。
- **Crossref** 兜底：仅当上述两者都查不到该论文时，用其 reference 列表补前置（Crossref 无被引方向）。

### 合并与去重

- 主键：`normalizeDoi`（复用现有函数）归一化后的 DOI 相同即同一篇。
- 无 DOI 条目：退化为归一化标题 + 年份匹配（复用现有候选匹配逻辑），仍无法匹配的作为独立节点保留。
- 字段合并规则：**更完整的字段胜出**——摘要取更长且完整的一方，被引次数取较大值，`isInfluential`、citation intent 等独有字段直接保留；发表日期遵循元数据规则，只有年份时不伪造 `YYYY-01-01`。
- 与本地论文库的匹配同样走 DOI 归一化，确保"本地库优先"不因 DOI 大小写或前缀差异漏判。

### 排序与数量

- 前置：本地库命中的全部保留；其余按 `isInfluential` 优先、再按被引次数排序，补充到约 6 篇。
- 后续：本地库命中的全部保留；其余按被引次数排序，补充到约 6 篇。

### 节点字段

标题、作者、年份、期刊、DOI、摘要（OpenAlex `abstract_inverted_index` 还原或 Semantic Scholar 摘要）、被引次数、是否在本地库、是否高影响力引用。

### 缓存

- 谱系结果落盘 `data/papers/lineage/<key>.json`，有效期 30 天，过期后重新拉取。
- **不进入一键导出包**：该缓存可随时从外部信源重新计算，属于运行时缓存，不适合迁移（按可配置功能导出规则在交付说明中注明）。

## 前端（public/index.html，原生 SVG，无新依赖）

- 详情页下方新增"引文谱系"板块，详情页打开后异步加载，不阻塞详情展示。
- 三层点线图：上排前置节点、中间当前论文（高亮）、下排后续节点，节点间连线表示引用关系。
- 节点悬停显示卡片：标题、期刊、年份、摘要片段、被引次数；本地库节点与外部节点用不同样式区分；高影响力引用有标记。
- 点击节点：本地库论文走现有详情页；外部论文进入临时详情页（样式同现有详情页），带"加入论文库"按钮，加入时写入操作日志。
- 追溯路径：一路点击经过的论文保留在后续图中并高亮（金色描边），可点击回退，与现有"返回上下文"机制衔接。
- 无 DOI 或所有信源未收录时显示"暂无谱系数据"，不报错。

## 错误处理

- 单信源超时/限流：使用另一信源结果，`sources` 字段注明实际来源。
- 外部论文详情拉取失败：临时详情页显示错误与重试按钮，不写入本地数据。
- 缓存文件损坏：忽略并重新拉取，不中断接口。
